# 记一次家庭聚餐

除夕前一晚，家庭聚餐，舅舅一家、姨父一家以及我们一家外加我外公和奶奶，共计十一人。晚辈共三人，我是最小的，两个哥哥分别比我大六岁和十二岁。之所以说自己是最大的受益者，是因为我还未参加工作，还能收压岁钱，并且这一次，压岁钱是真正属于我的。在上大学之前，父母都会收走压岁钱，以发给其他晚辈，而我基本上只能拿个零头当作零花钱。

这次聚餐，有几件事值得一提。

一是外公外婆二五年身体状况急转直下，又因为一些意外，外婆仍在住院，外公术后情况也大不如前，三位长辈为照顾老人忙碌了一年，目前情况相对稳定，感慨这一年过的不容易。

二是比我大六岁的那位哥哥（暂时记为P）正式参加工作第一年，同时又面临结婚问题，感觉被长辈狠狠压力了。P的女朋友比P小两三岁，安徽人，家中四个孩子，她排第二，家庭经济情况差P的家庭不少。舅舅提及几件和P女朋友相关的事情，综合表达了对她的不满意，但感觉关键还是在经济条件上。这种情况下，“最终决定权在你”这句话好像没有什么分量了。事实上，舅舅非常厉害，在找工作的时候给了P莫大的帮助，他的意见想必对P影响比较大，P可以说是两头为难了。

三是餐桌上出现了茅台。几位长辈聚餐喝点白酒也挺平常，不知道是因为我对酒变敏感了，还是今年确实不一样，这似乎是我在家庭聚餐上见到过最贵的酒了。与往年不一样的是，三位晚辈都被要求喝酒了。我虽然不是第一次喝白酒，但以往大多只是尝尝，没想到这次把几位长辈都敬了一遍。说实话，感觉茅台不好喝，细品不如一口闷。不过收了红包，敬一下几位长辈也是应该。大致一算，至少喝了有七八杯，没什么感觉。

第一次感觉到自己参加家庭聚餐的性质有了一些微妙的变化，幸好自己还在读书，该庆幸还是焦虑？我也不知道。

仅作分享。
